# PureScale Modern 1.2

- Added Fabric and NeoForge builds for 1.20.1, 1.21.1, 1.21.11, 26.1.x, 26.2 and 26.3.
- Carried Modern's DLSS SR, DLSS FG, FSR 4.1 and native download controls across the targets.
- Fixed the FPS overlay getting stuck at 10000 with native FG. Rendered FPS and the presented estimate are shown separately.
- Replaced broken overlay symbols with plain labels.
- Sodium is required throughout; NeoForge 1.20.1 requires Embeddium.

Neural Rendering remains experimental. The original runtime is not included. Radeon FSR 4.1 output still needs hardware testing.
