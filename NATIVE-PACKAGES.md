# Native packages

Get downloads these exact asset names from the latest release of `xsoras/purescale`:

| Asset | Contents |
| --- | --- |
| `purescale-modern-dlss-win64.zip` | DLSS SR bridges and runtimes |
| `purescale-modern-dlss-fg-win64.zip` | Combined DLSS SR + FG runtimes for OpenGL and the Vulkan FG path |
| `purescale-modern-fsr41-win64.zip` | FSR 4.1 bridge and runtime |

The paths inside those ZIPs are relative to `purescale_natives`. Get extracts them there automatically. For manual installation, create that folder inside the game instance and extract the chosen ZIP into it. Restart afterward.

`purescale-modern-1.2-all-versions-win64.zip` contains all 12 JARs and the shared native folder. Pick one JAR from it. Original Neural Rendering runtime files are not included.
