# Runtime packages

Get searches public, published stable releases in `XsoraS/purescale` for these exact asset names. The runtime ZIP can be in an earlier stable release; it does not have to be in the newest one.

| Asset | Feature |
| --- | --- |
| `purescale-modern-dlss-win64.zip` | DLSS Super Resolution |
| `purescale-modern-dlss-fg-win64.zip` | DLSS SR and Frame Generation |
| `purescale-modern-fsr41-win64.zip` | FSR 4.1 |
| `purescale-modern-dlss-nr-win64.zip` | Optional experimental Neural Rendering |

Keep these filenames unchanged when uploading. The release and repository must be public for Get to access them. Drafts and prereleases are skipped by the installer.

For manual installation, extract the chosen ZIP into `purescale_natives` in the Minecraft instance, preserving the internal paths, then restart. The JARs do not contain the native DLLs.

`purescale-modern-1.2-all-jars.zip` contains the 14 production JARs and documentation. Choose one JAR from it. It does not include native runtimes.
